if文の書き方は52ページに書いてありますが、
基本形のみ書いてあるだけです。
if-else if-elseの書き方も覚えてください。
if-else if-elseは１つの条件が偽であっても、
更にその後に条件を加えて分岐させることができる。

◆書き方
if(条件式１){
	条件式１が真（true）の場合の処理
}else if(){
	条件式１が偽（false）で条件式２が真（true）の場合の処理
}else{
	上記にある条件をいずれも満たさなかった時の処理
}


if文が書けるときにswitch文に変換することができる。
書き方はJava基本編で学んだ時の書き方になる（古い書き方）
switchの後ろの（）の中に条件の値（変数など）を入れ、
条件の値に対応したcaseにジャンプする。
caseの後ろには条件の値に合致する値とコロン（：）を書く。
その下に値に合致した時の処理を書いた後、
break;(break文とセミコロン)を書いて処理を終了させる。

◆書き方
switch(条件の値){
  case 値１：
    条件値と値１が等しい場合に実行する処理
    break;
  case 値２：
    条件値と値２が等しい場合に実行する処理
    break;
  default:
    上記の条件に当てはまらなかった場合に実行する処理
}
