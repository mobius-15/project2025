文字列の文字を抜き出すメソッドで、似ているメソッドがあるのでその説明をします。

■テキストではsubstr()を紹介しています。
第一引数：文字列を取り出す開始位置（どこから取り出しはじめる）
第二引数：取り出す開始位置を１番目としたときの取り出す文字数（何文字取り出す）

substring()とslice()はsubstr()と第二引数の意味が違う。
第一引数：文字列を取り出す開始位置（どこから取り出しはじめる）
第二引数：文字列を取り出す終了位置（どこまで取り出す）

例：「ようこそとぴあＩＴスクールへ」から「とぴあＩＴスクール」を抜き出す場合
substr() 　→　substr(4,9)
substring()　→　substring(4,13)
slice()　→　slice(4,13)

■第二引数が省略されるときは、開始位置から最後まで抜き出す。
よってすべてのメソッドが「とぴあＩＴスクールへ」と表示する
substr() 　→　substr(4)
substring()　→　substring(4)
slice()　→　slice(4)

■第二引数が省略され、第一引数がマイナスの時
substr()　文字列の後ろから数えた位置が開始位置になる
substr() 　→　substr(-5)　→　「スクールへ」
substring()　開始位置を「0」と認識する
substring()　→　substring(-5)　→　「ようこそとぴあＩＴスクールへ」
slice()　文字列の後ろから数えた位置が開始位置になる
slice()　→　slice(-5)　→　「スクールへ」

■第一引数がマイナス値で第二引数がプラス値
substr()　
第一引数：文字列の後ろから数えた位置が開始位置になる
第二引数：取り出す開始位置を１番目としたときの取り出す文字数（何文字取り出す）
substr() 　→　substr(-5,4)　→　「スクール」

substring()　
第一引数：開始位置を「0」と認識する
第二引数：頭から数えた時の文字列を取り出す終了位置（どこまで取り出す）
substring()　→　substring(-5,4)　→　「ようこそ」

slice()　表示されない（エラー状態）

■第一引数がマイナス値で第二引数もマイナス値
substr()　表示されない（エラー状態）　
substring()　表示されない（エラー状態）

slice()
第一引数：文字列の後ろから数えた位置が開始位置になる
第二引数：文字列後ろから数えた位置が終了位置になる
slice()　→　slice(-5,-1)　→　「スクール」

となる。
